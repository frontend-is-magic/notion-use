# 按语义选文风与视觉

类型是默认组合，可混合；不套用固定章节数。

| 类型 | 文风/主体结构 | 正文视觉 | 图标与封面 |
| --- | --- | --- | --- |
| 科普解释 | 准确定义→机制→有边界的类比→常见误解，区分事实与假说 | 科普漫画、规范标注的示意图；数据图按真实数据绘制 | 主题对象、克制纸面科普插画 |
| 知识文档 | 问题/结论先行，概念与例子配对，概念层次明确 | Mermaid 流程/分类图、局部示例 | 主题符号、清晰结构式编辑插画 |
| 摘要/简报 | 先给结论，保留关键事实、差异与行动，去掉过程复述 | 纯文字；必要数据可简短列举 | 极简封面和图标，封面不充当正文插图 |
| 随记/灵感 | 保留个人语气和原始判断，只做必要整理，不伪造完整论证 | 默认无图，确有帮助再用小速写 | 轻松手绘、留白，色彩贴合情绪 |
| 操作指南/SOP | 前提→最少必要步骤→预期结果→失败分支 | 流程图或实际步骤示意，不生成伪截图 | 工具或动作意象 |
| 技术设计/方案 | 目标与约束→决定→结构→接口→取舍与边界 | 精确 Mermaid 架构/时序图，源码示例 | 几何、工程草图，避免无意义科技霓虹 |
| 调研/比较 | 先给适用结论，列比较维度与证据，区分事实和推断 | 对比表、真实数据图；禁止虚构权威论文配图 | 中性编辑插画 |
| 决策记录/ADR | 决策一句话→背景→备选→理由→影响，记录时间与状态 | 少图，必要时决策树 | 单一清楚的选择意象 |
| 复盘/故障分析 | 影响→根因→证据链→修复→预防，区分静态分析与复现 | 时间线、因果图，日志折叠 | 冷静克制，避免灾难渲染 |
| 项目/执行计划 | 目标、里程碑、依赖、验收、负责人仅使用已知值 | 简短时间线或依赖图 | 路径与阶段意象 |
| 学习路线/课程 | 先说明学成后能做什么，阶段目标→练习→验收 | 概念地图/学习路径；资源带原始链接 | 清楚的成长路径插画，避免鸡汤 |
| 会议纪要 | 决定、行动、未定事项前置；不虚构发言和负责人 | 默认纯文字，原始讨论折叠 | 中性记录/对话意象 |
| 清单/索引/FAQ | 便于扫描、可检索，入口简短且去重 | 默认无图或分类图 | 简单分类符号 |
| 观点/评论 | 观点→具体依据→反例/限制，保留作者立场 | 有明确论证价值才加图 | 个人化但克制的编辑插画 |

共通要求：中文自然、短句与适度长句交替、术语只在有用时解释；少喊口号，少“首先其次最后”的机械排比，不使用万能收尾。画面不能出现无意义文字、乱码标注、虚构数据、品牌假截图；解释性图必须与正文一致。摘要的“纯文字”约束只约束正文，不取消页面视觉。
